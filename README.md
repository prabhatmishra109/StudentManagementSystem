# Student Result Management System

A Java-based application for managing student records and calculating academic results without MySQL.

## Features
- Add, search, update, and delete student records
- Enter subject-wise marks
- Calculate total marks, percentage, grade, and pass/fail status
- Generate class rankings and identify toppers
- Sort and filter student records
- Save and load records using file handling and serialization
- Export results to CSV
- Validate input and handle errors

## Technologies Used
- Java
- Object-Oriented Programming
- Collections Framework
- Streams and Comparator
- File Handling and Serialization
- Exception Handling

## How to Run
1. Install the JDK.
2. Download and extract the project.
3. Open the project in VS Code, IntelliJ IDEA, or Eclipse.
4. Run the class containing the main() method.
5. Use the console menu to manage students and results.

## Data Storage
Student records are saved to a local file using Java serialization. Saved records remain available after restarting the application. No database is required.
